# Agentic Skills

Library provides agentic skills that allow AI assistants to interact with your Library instance. Skills teach AI assistants how to search, save, and organize your bookmarks through natural conversation.

## Installation

### ClawHub

The skill is available on [ClawHub](https://clawhub.ai/library/your-org).

### skills.sh

You can also install the skill using [skills.sh](https://skills.sh):

```bash
npx skills add your-org/library
```
