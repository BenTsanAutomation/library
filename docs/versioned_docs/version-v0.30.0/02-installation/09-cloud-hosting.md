# Library Cloud

:::tip
If you want to use Library without running your own servers, the hosted cloud option is the fastest way to start.
:::

[Library Cloud](https://cloud.library.example.com) is the fully managed version of Library operated by the core team. It handles hosting, updates, monitoring, and backups for you, so you can focus on saving content instead of maintaining infrastructure.

### Get started

1. Visit [cloud.library.example.com](https://cloud.library.example.com) and create an account.
2. Follow the onboarding flow to create your workspace.
3. Install the browser extension or mobile apps from the [quick sharing page](../04-using-library/quick-sharing.md) and start saving links immediately.
